# 魔法陣工房 — Arcanum Circle Generator

属性・階位・シードから魔法陣を決定的に生成するジェネレーター。単一HTMLで動作し、ビルド不要・依存ライブラリなし（Google Fontsのみ）。

**Demo**: https://Vaduz.github.io/magic-circle/

## 特徴

- **意味論ベースの生成**: 錬金術の四大元素記号・数秘術に基づき、色相・星型多角形 {n/k}・回転方向・環数を属性（火/水/風/土/光/闇）から論理的に導出
- **決定的生成**: 同じ (術式, 階位, シード) は必ず同じ魔法陣（FNV-1a + mulberry32）
- **自作術式モード**: 色相・星型・回転・シジル・ルーン文字系などフルパラメータ調整
- **詠唱シーケンス**: 下絵→着色→環の発現→ルーン点灯→星型刻印→完成の段階アニメーション。タイムラインエディタで各層の開始/終了をドラッグ編集、スクラブプレビュー対応
- **効果音**: Web Audio によるリアルタイム合成（音源ファイル不要）。属性ごとに波形・基音が変化
- **3D表示・重奏**: ドラッグ回転・ピンチ拡縮、最大3層の多重展開
- **SVG書き出し**: 詠唱アニメーション込みの単体SVGをダウンロード可能

## 技術メモ

- グローは feGaussianBlur ではなくストローク下敷きで表現（モバイルWebKitでのフィルタ再ラスタライズ負荷対策）
- 3Dは preserve-3d を使わず、各層に同一ビュー行列を個別適用（WebKit互換性対策）
- 線描画アニメーションは `pathLength="1"` を `<path>` 要素に限定して使用

## ローカル実行

```
open index.html   # ブラウザで開くだけ
```

## 術式の共有（パーマリンク）

「🔗 共有リンクをコピー」で現在の術式をURLとして共有できます。

```
?e=fire&p=7&s=1024&l=3&g=90          # 属性術式: 火・階位VII・3層重奏
?m=c&h=120&n=9&k=4&si=moonstar&p=6   # 自作術式: 全パラメータをURLで指定
```
